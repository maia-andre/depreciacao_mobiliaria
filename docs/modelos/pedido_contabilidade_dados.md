# Modelo — pedido à Contabilidade: dados para conciliação com o Patrimônio

**Assunto:** Saldos e lançamentos das contas de bens móveis, para o projeto de depreciação

Estamos montando a base de bens móveis para a implantação da depreciação e precisamos conferir o cadastro do Patrimônio com os registros contábeis.

## 1. Saldos das contas de bens móveis

Saldo de cada conta contábil de bens móveis (PCASP) nas datas de corte do projeto (por exemplo, o último fechamento anual e a data mais recente disponível).

Se existir alguma conta de depreciação acumulada de bens móveis com saldo, incluir também.

## 2. Lançamentos de baixa de bens móveis

Todos os lançamentos de baixa de bens móveis do período analisado, com:

| Campo | Para quê |
|---|---|
| Data do lançamento | Comparar com a data de baixa no Patrimônio |
| Conta contábil | Saber de que conta o bem saiu |
| Valor | Comparar com o valor dos bens baixados |
| Histórico / documento | Número do processo, expediente ou leilão, para casar com as baixas do Patrimônio |

O objetivo é entender em que momento a Contabilidade lança a baixa (na declaração do bem como inservível ou no leilão) e conciliar baixa a baixa.

## 3. Lançamentos de incorporação (se possível)

Entradas de bens móveis no mesmo período (aquisição, doação recebida), com data, conta, valor e histórico (empenho, nota fiscal ou processo).

**Formato:** Excel ou CSV.
